# 作者使用 Way Live 的演示记录

录制日期：2026-10-15，由作者在个人电脑上录制。本次使用更新后的 Way Live 界面，以独立的杭州三日测试旅行发起一次真实规划请求。随后查看同一份计划的地图和当天路书，并导出 PDF。

| 操作 | 已验证的结果 |
| --- | --- |
| 实时规划 | 根据上海出发、杭州三天、一人、不自驾、西湖散步与市区美食的输入，交付三天路线与每日安排 |
| 规划耗时 | 本次界面记录约 108.6 秒；GIF 压缩了等待与镜头间隔 |
| 路线地图 | 底图实际加载完成后录制，显示城市、水系与路线 |
| 当天路书 | 点击第 2 天，展示活动、交通与安排理由 |
| PDF 导出 | 成功生成本次路线的六页 PDF 文件 |

[查看新版 GIF](media/live-demo-20261015.gif)。动图约 18 秒，等待片段与镜头间隔已压缩。本次是单独功能演示，原测试报告的统计批次与结果保持不变。

Way 实时规划暂不对公众开放；公开页面使用预设案例控制模型调用成本。
