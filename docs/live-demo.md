# 作者使用 Way Live 的演示记录

录制日期：2026-10-15，由作者在个人电脑上录制。演示使用独立的杭州三日测试旅行，发起一次真实规划请求；后续操作继续使用这次规划保存后的结果。

| 操作 | 已验证的结果 |
| --- | --- |
| 实时规划 | 根据上海出发、杭州三天、一人、不自驾、西湖散步与市区美食的输入，交付三天路线与每日安排 |
| 规划耗时 | 本次界面记录约 87.5 秒；GIF 压缩了等待与镜头间隔 |
| 路线地图 | 详细底图加载完成，显示地形、水系、城市与路线；首次绘制时独立地图 worker 正常加载 |
| 当天路书 | 点击第 2 天，展示活动、交通与安排理由 |
| PDF 导出 | 成功生成本次路线的六页 PDF 文件 |

[查看 GIF](media/live-demo.gif)。本次是单独功能演示，原测试报告的统计批次与结果保持不变。

Way 实时规划暂不对公众开放；公开页面使用预设案例控制模型调用成本。
