# Way

Way 是一款 AI 自由行规划工具，将地图上的路线与每天的旅行攻略放在同一份计划中。路线告诉你去哪、怎么走；路书写清每天怎么玩、要准备什么。你可以通过旅行案例体验挑选地点、生成行程和调整安排的过程。

## 从哪里开始

当前公开体验范围为“看案例”（Showcase），收录大阪与鸟取、新西兰南岛、大理三个旅行案例。你可以在案例提供的地点与体验中选择，生成路线和每日路书，再通过页面上的对话选项调整安排。案例使用预设旅行条件、资料和对话内容。

“自由规划”（Live）支持自由输入目的地、兴趣和出行条件，根据这些要求规划自己的旅行，并在需要时查询资料。目前尚未向公众开放。

三个案例分别是大阪与鸟取约 7 天、新西兰南岛约 12 天、大理约 7 天，均将从上海出发和返回的交通计入总天数。案例里的航班、酒店和车票仅作为规划条件，不代表已经预订。

## 怎样体验一个案例

1. **选择一趟旅行**：打开一个案例，查看预设的出发地、天数、同行情况、兴趣和交通条件。
2. **挑选想去的地方**：阅读地点与体验介绍，勾选想保留的内容；可以换一批继续选择，已选内容会保留。
3. **查看路线和路书**：路线展示地点顺序、交通和住宿区域；每天的路书介绍怎么玩、要花多久、需要预约或准备什么。
4. **体验行程调整**：增减勾选的体验，或选择页面提供的调整选项，查看路线与每日路书怎样随之变化；也可以撤销最近一次行程修改。

旅行计划支持保存、恢复、撤销修改和导出 PDF。计划保存在当前浏览器，暂不支持跨设备同步。

## 路线与路书包含什么

- **完整时间线**：从出发日开始，计入去程、返程、必要的接送与休息；未知航班或车次标为待确认。
- **逐日安排**：写清地点、要做的事、建议停留时间、交通衔接、安排理由和可以删减的内容。
- **选择与取舍**：保留明确选中的体验；若时间或交通冲突，解释如何缩短、替换或调整。
- **住宿与行前准备**：建议住在哪个区域、何时需要换住，以及开放、预约、天气、交通等仍需按实际日期核实的事项。
- **参考资料与待确认事项**：相关内容附有可打开的参考链接；尚未确认的价格、班次和开放条件会标明待核实。

路线地图用来查看地点位置和行程顺序，不提供道路导航。

## 当前边界

- Way 提供规划建议，不代办订票、付款、改签或取消。
- 价格、座位、天气、开放时间与班次会变化；出发前应以实际日期和运营方信息复核。
- 地图位置是区域示意；无法可靠定位的地点会注明，出行时请使用导航地图确认具体位置。
