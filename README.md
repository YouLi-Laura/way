收藏夹里存了不少好地方，真要出发时，还是得重新打开地图：哪些能放在同一天，住在哪里方便，往返路上又要留多久。

Way 想帮你把这些安排理顺。说说想去哪里、和谁去、准备玩几天，挑出感兴趣的地方，再看看它们怎样串成一趟旅行。哪天太赶了，就再聊几句、改一改。地图和每天的路书放在一起，定好后导出 PDF，出门时带着看。

## 先试试这三趟旅行

- **大阪＋鸟取，约 7 天。** 一个人逛大阪街区、吃点当地小吃，再去砂丘和柯南小镇走走。
- **新西兰南岛，约 12 天。** 和朋友自驾，看山看湖，沿途的小镇也留些时间逛逛。
- **大理，约 7 天。** 陪父母慢慢逛，吃饭、散步、歇一歇，往返也不赶路。

[选一趟，进去看看 →](https://youli-laura.github.io/way/)

**实时规划目前仅本机可用，暂不对公众开放。** 为控制模型调用成本，网页先开放 Showcase 案例演示。你可以用预设案例挑地点、排路线、试着调整，再导出 PDF。

## 这一天，去哪里、怎么走

<a href="https://youli-laura.github.io/way/">
  <img src="docs/media/route-preview-complete.png" alt="大阪与鸟取案例的路线地图，标出了每日地点和上海往返交通。" width="1280" />
</a>

地图上的每个日期，都对应着当天的安排。点开看看：上午去哪儿，下午怎么接着走，交通怎么衔接，有什么需要提前确认。

计划也可以接着商量。想少去一站、把第二天安排得轻松些，就继续告诉 Way。调整时，路线、每天的玩法和相关提醒会一起更新；改完不满意，还可以撤销。本机实时规划会保存进度，下次可以接着安排；公开案例每次从最新的案例选择页开始。
